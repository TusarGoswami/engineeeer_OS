# EngineerOS Admin & Faculty Operations Guide

## Overview
The Admin & Faculty Studio (`/admin`) provides institutional administrators and professors with full lifecycle management for:
1. **Algorithm Problem Authoring**: Multi-language starter code templates (Python, C++, Java, JS), standard and hidden test cases, execution memory/time quotas.
2. **Scheduled Proctored Assessments**: Real-time browser lockdown, fullscreen verification, tab blur auditing, automated grading.
3. **Integrity Telemetry Moderation**: Audit student violation logs (`tab_hidden`, `fullscreen_exit`), apply proportional marks penalty or void attempts.
4. **Alumni & Senior Governance**: Verify alumni credentials, companies, graduation year, and award the gold Verified Alumni Mentor badge.

## RBAC Permissions
- **Platform Admin**: Unrestricted write access across institutional catalog, moderation verdicts, user roles.
- **Content Admin**: Problem creation, test case uploads, assessment scheduling, integrity reviews.
