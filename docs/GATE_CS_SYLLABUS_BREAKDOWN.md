# GATE Computer Science Subject Weightage Breakdown

| Section | Subject | Approximate Marks | High-Yield Topics |
| :--- | :--- | :--- | :--- |
| **GA** | General Aptitude | 15 Marks | Numerical reasoning, spatial ability, English grammar |
| **EM** | Engineering Mathematics | 13-15 Marks | Discrete math, graph theory, probability, linear algebra |
| **CS Core** | Data Structures & Algorithms | 14-16 Marks | Asymptotic analysis, trees, graphs, dynamic programming |
| **CS Core** | Operating Systems | 8-10 Marks | Virtual memory, CPU scheduling, synchronization, deadlocks |
| **CS Core** | Computer Networks | 8-10 Marks | TCP/IP, flow control, subnets, routing algorithms |
| **CS Core** | Database Management (DBMS) | 7-9 Marks | Normalization (3NF/BCNF), transactions, SQL, indexing |
| **CS Core** | Theory of Computation (TOC) | 7-9 Marks | Regular languages, DFA/NFA, context-free grammars, decidability |
| **CS Core** | Compiler Design | 4-6 Marks | Lexical analysis, LL(1)/LR(1) parsers, intermediate code |
| **CS Core** | Computer Organization (COA) | 8-10 Marks | Pipelining, cache mapping, instruction addressing modes |
