# Competitive Programming Quick Reference

## Time Complexity Bounds (1-Second Sandbox Budget: ~10^8 operations)
- **N <= 10**: O(N!) or O(2^N) - Backtracking, bitmask DP
- **N <= 20**: O(2^N * N) - Traveling salesperson, bitmask subsets
- **N <= 500**: O(N^3) - Floyd-Warshall, matrix exponentiation
- **N <= 5000**: O(N^2) - 2D dynamic programming, bubble/insertion sort
- **N <= 10^5**: O(N log N) - Binary search, merge sort, segment trees, heaps
- **N <= 10^7**: O(N) - Two pointers, sliding window, prefix sums, sieve
- **N >= 10^9**: O(log N) or O(1) - Binary exponentiation, GCD, math formulas
